# CO2 Streaming Trees

Interactive visualization of streaming decision trees for CO₂-related prediction models.

The project shows how tree structures, split variables, thresholds, feature importance, and prediction accuracy evolve over time for different streaming-learning configurations.

## 🌐 Open the interactive visualization

👉 **[View the CO2 Streaming Trees app](https://kirstenml.github.io/CO2StreamingTrees/)**

Use the dropdown to select a model configuration and the time slider to explore how the decision tree changes over time.

## Repository

Source code and generated model results are available here:
