# CO2 Streaming Trees

Interactive visualization of streaming decision trees for CO₂-related prediction models.

The project shows how tree structures, split variables, thresholds, feature importance, and prediction accuracy evolve over time for different streaming-learning configurations.

## 🌐 Interactive visualization

👉 **[Open the CO2 Streaming Trees visualization](https://kirstenml.github.io/CO2StreamingTrees/)**

Use the dropdown to select a model configuration and the time slider to explore how the learned decision tree changes over time.

## About

The visualization is built as a static GitHub Pages application using HTML, JavaScript, and `vis-network`. Model snapshots and results are stored as text files and loaded dynamically into the viewer.
